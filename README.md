# 小白 · 健康陪伴助手（本地网页版）

一个在自己电脑上跑的健康问答小助手：判断要不要紧、在家先做什么、什么时候必须去医院、哪些事别做。
不诊断、不开药、不给剂量，遇到急症第一句先让你打 120。

## 一、怎么打开

1. 双击目录里的 **启动小白.bat**（需要电脑上装有 Python 3.9 及以上）。
2. 会弹出一个黑色窗口，浏览器自动打开 **http://127.0.0.1:8765/**。
3. 用完直接关掉黑色窗口即可，不占后台、不联网、不上传任何内容。

如果浏览器没有自动打开，手动在地址栏输入上面的地址。黑色窗口不要关，关了服务就停了。

命令行方式：

```bat
cd /d 本目录
python app.py --open
```

端口被占用时会自动顺延到 8766、8767，窗口里会打印实际地址。

## 二、怎么用

直接说人话就行，不用组织语言。例如：

- 胸口像被压着，一直出汗，左胳膊也疼
- 孩子发烧 38.5 度，精神还行
- 最近总失眠，躺下两小时睡不着
- 拉肚子一天四五次，水样的
- 挂什么科（会接着上一轮的症状回答）

回复分三层：先判断风险，再给现在能做的事，最后给"出现这些情况别拖"和"这几件事先别做"。
每条回复底下有风险等级和知识库依据，可以点喇叭用系统语音朗读。

## 三、能做什么、不能做什么

能做：

- 9 类危险信号识别：压榨性胸痛、呼吸困难、晕厥、抽搐、呕血黑便、卒中征象、儿童高热惊厥、心理危机、严重过敏
- 11 类常见症状的科普与就医分级：成人发热、儿童发热、头痛、咽痛、咳嗽、腹泻、呕吐、腹痛、普通感冒、头晕、失眠
- 儿童、孕妇、老人自动上调一档风险判断
- 心理危机直接给 12356，急症给 120
- 反问"挂什么科"这类追问，会结合上一轮回答

不能做：

- 不做诊断、不判断具体病名
- 不给药名剂量，只提醒按说明书或医嘱
- 知识库没覆盖的问题会直说"没查到可靠资料"，不编
- 不能替代面诊，急症请直接打 120

## 四、目录结构

```
小白_健康助手/
├─ 启动小白.bat          双击启动
├─ app.py                本地网页服务（页面 + 对话接口）
├─ xiaobai_agent.py      对话引擎（M1 关键词 → 风险分流 → 检索 → M2 推理 → M3 表达）
├─ web/index.html        聊天界面
├─ 知识库/
│  ├─ K1_危险信号与急救/  9 篇
│  └─ K2_常见症状/        11 篇
├─ 预览/                 界面截图
└─ 使用说明.md
```

知识库是普通 Markdown 文件，每篇固定七段：一句话结论、常见表现、可能原因、在家可以先做、这些情况要就医、不要做、参考来源。
想加症状，按同样格式新建 .md，放进对应目录，重启服务即可生效。

## 五、和扣子版的对应关系

本地版就是按扣子那 9 个节点跑的逻辑，只是把大模型换成了本地规则 + 检索：

| 扣子节点 | 本地实现 |
| --- | --- |
| 开始 | 页面输入框 |
| M1 关键词提炼 | `m1_extract()`，规则 + 口语同义词 |
| 风险分流 | 9 类危险信号正则，命中直接走安全兜底 |
| 知识库检索 | 本地 TF-IDF 式检索，K1/K2 分流 |
| 任务分流 | 用药、情绪、生活方式走直答 |
| M2 医学推理 | `m2_reason()`，只取知识库原文，不生成 |
| M3 温暖表达 | `m3_express()`，固定结构 + 免责声明 |
| 安全兜底 | 九类固定话术，不经过模型 |
| 结束 | 回复 + 追问建议 |

## 六、常见问题

**提示找不到 Python**：先装 Python 3.9+，安装时勾选 "Add Python to PATH"。

**页面打不开**：看黑色窗口是不是被关了；或浏览器访问窗口里打印的地址。

**语音没声音**：换 Edge 或 Chrome；系统需要装有中文语音包。

**数据去哪了**：只在本机内存里，关掉窗口就没了，不写数据库、不上传。
